      How to use

      Getting started

      1. Power the board and press Connect. Pick NPG-IR from the browser dialog.
      2. Press the lock icon to unlock, then press + on a remote and name it.
      3. Open the remote, press + on a command, then point a real remote at the board and press a key.
      4. Name the capture and save it. Lock again when you're done setting up.
      5. Press a command's send button to fire it.

      Muscle and brain control

      Open Controls in the header to pick a channel, a filter and a gesture for each of the four actions. The bar beside each one shows its live level, and the slider sets the threshold that counts as a gesture: put it just above your resting level and below a deliberate one.

      Requirements

      Web Bluetooth works in Chrome and Edge on desktop and Android. Firefox and Safari do not support it. On Android, Location must be on for Bluetooth scanning.

      Erase all

      Removes every remote, command and waveform from the board. This cannot be undone.

      Browser not supported

      This browser does not support to Bluetooth devices. Open this page in any Chromium based browser like Chrome, Brave or Edge to connect your NPG-Lite.
